## Deliverables

1. **`docs/M4-case-study.md`**: a complete attribution report on a sqlite insert benchmark. Structure: anomaly observed at the monitoring layer (node_exporter via Prometheus) → hypothesis list → eBPF evidence (runqlat, offcpu, biolat) → conclusion.

2. **Re-runnable scripts** (`scripts/m4/`):
   - `sqlite_bench.c` — the workload: one transaction per row, `journal_mode=DELETE`, `synchronous=FULL`, so each commit fsyncs and is sensitive to block IO latency.
   - `run_baseline.sh` — baseline throughput run.
   - `run_anomaly.sh` — injects a background fio random-writer (iodepth=32) and runs the benchmark on top.
   - `attribution_offcpu.sh` — asserts offcpu attributes `sqlite_bench` to the fsync/commit path.
   - `attribution_biolat.sh` — asserts biolat's anomaly median exceeds the baseline median.

3. **`scripts/verify_m4.sh`**: smoke regression re-running all four conclusions and asserting each holds.

4. **`ci_report.sh` M4 section** (already present) runs `scripts/verify_m4.sh`.

## The Case Study

- **Anomaly observed at monitoring layer**: node_exporter showed ~950 writes/s and moderate disk utilization on vda, load ~1.4 — but could not explain why inserts were slow or what changed when throughput dropped.
- **Hypotheses**: CPU saturation, lock contention, or block IO latency.
- **eBPF evidence**:
  - runqlat: tail (>=64us) fraction stayed at baseline (~31/1000) during the benchmark → not CPU-saturated.
  - offcpu: `sqlite_bench`'s dominant stack is `__x64_sys_fdatasync → ext4_sync_file → folio_wait_writeback → io_schedule` → the synchronous commit path.
  - biolat: under the injected anomaly, the block IO latency peak shifted from the 256–511us bucket to 512–1023us with a tail out to ~262ms (median roughly doubled).
- **Conclusion**: the benchmark is fsync-bound; the background writer inflated block IO latency, halving throughput (~345 → ~166 rows/sec). The monitoring layer could not attribute this; eBPF could. The anomaly was injected deliberately (a known cause), as permitted by ROADMAP M4.

## Deviations from ROADMAP

1. **Anomaly is injected, not naturally occurring** — explicitly permitted by ROADMAP M4 ("if no natural anomaly occurs during the experiment, injecting a known anomaly and documenting that fact is permitted"). This machine's workload is too uniform to produce a spontaneous block IO anomaly on schedule.

2. **verify_m2.sh workload increased** (32M→64M, iodepth 8→16): the original workload occasionally completed too quickly for a reliable histogram, causing a transient M2 oracle failure when run in the full regression. Increased for stability; parameters remain fixed.
